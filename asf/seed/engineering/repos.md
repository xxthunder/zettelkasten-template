# Repositories

[← Engineering](README.md)

The repos this Kasten points into. Log lines ([log.md](log.md)) and learnings address a repo
by the name in the first column; the remote is what a skill or `git` uses, the link on the
name is what a human opens. Nothing here links back. Where a repo is cloned locally, it sits
at `~/dev/<org>/<repo>` — look there before cloning.

| Repo | Remote | IDs | What it is |
|---|---|---|---|

## Jira projects

Work that a team keeps in Jira gets a board card by `<name> <KEY-123>`, where `<name>` is the
first column here. The name links to the project; Site is the Jira base URL, Key the project
key.
