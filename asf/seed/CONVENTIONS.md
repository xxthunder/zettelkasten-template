# Zettelkasten Conventions — this Kasten

The shared rules — principles, file names, frontmatter, linking, tags, engineering log, what
is English — stand in **[asf/CONVENTIONS.md](asf/CONVENTIONS.md)** and belong to the template.
This file adds this Kasten's own areas and the language of its notes.
**Claude Code: read both files before editing notes.**

## Areas

None of its own yet. An area adds a line here — folder, `type` value, file names — and a
section in [AGENTS.md](AGENTS.md).

## Language

What is English everywhere is fixed in [asf/CONVENTIONS.md](asf/CONVENTIONS.md) → Language.
Everything else in this Kasten — area notes, hubs, `docs/`, the conversation with the
agent — is **English** too. Change this line to pick another language for them.
