# Zettelkasten

Notes in Markdown, versioned with git and worked on with Claude Code. Atomic notes connected
by links — the value lies in the connections, not in the number.

The rules stand in [asf/CONVENTIONS.md](asf/CONVENTIONS.md) — the template's part — and in
[CONVENTIONS.md](CONVENTIONS.md) for this Kasten's own areas. What the Agentic Software Forge
is, which `asf/` comes from, explains [asf/README.md](asf/README.md).

## Map of content

- **[learnings/](learnings/README.md)** — what outlives a project: one claim per note, in own
  words, in English
- **[literature/](literature/README.md)** — summaries of sources, in own words
- **[engineering/](engineering/README.md)** — tinkering, the [log](engineering/log.md) across
  all repos, the [registry](engineering/repos.md) of repos and the [ranked list](engineering/next.md)
- **inbox/** — raw captures; `process inbox` turns them into notes
- **[docs/](docs/backlog/README.md)** — the backlog and the [decisions](docs/decisions/README.md)
  of this Kasten
